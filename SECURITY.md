# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues.

If you find a vulnerability, report it privately to the project maintainer with:

- A clear description of the issue
- Steps to reproduce
- Affected versions or commits, if known
- Any suggested mitigation

Avoid including real credentials, tokens, private data, or exploit details that
are not necessary for reproducing the issue.

## Supported Versions

This project is maintained as a small open-source project. Security fixes are
handled on the main branch unless a separate release branch is announced.
